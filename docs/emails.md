# אבן דרך — תוכן מיילים

עריכה: שנה את הטקסט בעברית בשדות למטה (נושא, כפתור, פסקאות).  
אחרי שמסיימים — תגידו לי ליישם בקוד. הקובץ הזה **לא** נשלח אוטומטית; הוא טיוטת תוכן.

משתנים בסוגריים מסולסלים (`{שם מלא}`) נשארים כמו שהם אלא אם ביקשתם לשנות.

---

## מעטפת משותפת (כל המיילים)

מופיעה מעל ומתחת לתוכן הספציפי.

- כותרת כהה: `אבן דרך`
- תת־כותרת: `יחפ״צ · היחידה הארצית לפינוי צירים`

---

## 1. הזמנה למשתמש חדש

נשלח כשמנהל יוצר משתמש, או בלחיצה על **שליחת הזמנה מחדש**.  
שולח: `אבן דרך - יחפ״צ <invites@send.yahpz.com>`

**נושא**

```
הוזמנת למערכת אבן דרך - יחפ״צ
```

**כפתור**

```
להשלמת הרישום
```

**גוף**

```
שלום {שם מלא},

הוזמנת למערכת 'אבן דרך' - מערכת הניהול של היחידה הארצית לפינוי צירים.

לכניסה ראשונית למערכת והגדרת סיסמה, יש ללחוץ על הקישור.

[כפתור]

או להעתיק את הכתובת: {קישור הזמנה}

אם לא ציפית להזמנה זו, ניתן להתעלם מההודעה
```

---



## 2. דיווח מוכן להשלמה

נשלח פעם אחת לכונן כששובץ לאירוע, או כשאחמ״ש מזין ק״מ לראשונה.  
שולח: `אבן דרך - יחפ״צ <alerts@send.yahpz.com>`

**נושא**

```
אירוע ממתין לתיעוד - אבן דרך
```

**כפתור**

```
להשלמת התיעוד
```

**גוף**

```
שלום {שם מלא},

שובצתם לאירוע. ניתן כעת לתעד פרטים, גם לפני הזנת הקילומטרים.

{תאריך} · {סוג אירוע} · {כביש}

[כפתור]



שובצת לאירוע בטעות? התעלם מהודעה זו וצור קשר עם אחד האחמ"שים
```

---



## 3. חריגת זמנים בתיעוד (48 שעות / 7 ימים)

אותו מייל פעמיים: אחרי 48 שעות, ואז אחרי 7 ימים. משתנה רק משך ההמתנה.  
שולח: כמו מייל 2.

**נושא**

```
חריגת זמנים בתיעוד אירוע - אבן דרך
```

**כפתור**

```
להשלמת התיעוד
```

**שורה לפי מועד** (נבחרת אוטומטית)

```
יש לך אירוע שממתין לתיעוד מעל ל־48 שעות
```

```
יש לך אירוע שממתין לתיעוד מעל ל־7 ימים
```

**גוף**

```
היי, {שם מלא}

{שורה לפי מועד}

{תאריך} · {סוג אירוע} · {כביש}

אפשר ללחוץ כאן כדי להשלים את התיעוד

[כפתור]

שימו לב! אירוע שלא יתועד במלואו לא יחושב להחזר הדלק הרבעוני
```

---



## 4. תפוצה (מייל יחידה)

המנהל כותב **נושא** ו**גוף** במסך תפוצה. מה שקבוע בקוד הוא רק המעטפת והברכה.

**ברכה**

```
שלום {שם מלא},
```

(אם אין שם: `שלום,`)

**גוף**

```
{תוכן שהמנהל כתב במסך תפוצה}
```

שולח: `אבן דרך - יחפ״צ <invites@send.yahpz.com>`
