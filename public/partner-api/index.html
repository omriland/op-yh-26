Connect a Telegram bot

MCP-style: authorize once from the bot, then call the HTTP fill actions.

For volunteers

  1. Open the connect link from the Telegram bot.
  2. Sign in on yahpz.com if needed.
  3. Tap Confirm and continue to Telegram. Done.

Revoke later in Profile → Connections → Revoke access. There is no connect button on the profile — start from the bot.

For bot builders

  1. An admin registers the bot once in Settings (Register bot) and sends you a client id and token.
  2. Send a short authorize URL: /oauth/authorize?client_id=…&state=…
  3. When the volunteer finishes connecting, Telegram sends you /start yp_…
  4. Exchange the code for a token and call the fill actions.
