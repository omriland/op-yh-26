חיבור לבוט בטלגרם

הכונן לא ממלא מפרט. הוא נכנס לחשבון ולוחץ כפתור אחד.

לכונן

  1. נכנסים ל־yahpz.com ומתחברים.
  2. פרופיל ← חבר לטלגרם.
  3. טלגרם נפתח. זהו.

אם הקישור הגיע מתוך הבוט: מתחברים באתר, לוחצים אשר והמשך לטלגרם, וחוזרים לצ׳אט. בטלים בפרופיל ← בטל גישה.

למי שבונה את הבוט

  1. מנהל רושם את הבוט פעם אחת בפרופיל (רישום בוט) ומעביר לכם מזהה וסוד.
  2. כשהכונן מסיים את החיבור, טלגרם שולח אליכם /start yp_…
  3. אתם מחליפים את הקוד באסימון וקוראים לפעולות המילוי.
